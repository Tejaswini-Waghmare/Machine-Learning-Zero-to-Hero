# Feature Engineering and Selection

Study **feature interactions, polynomial features, feature selection, validation-safe transforms**.

## Files
- `Study_Notes.md`: explanations and pitfalls
- `Examples.ipynb`: runnable demonstration
- `Practice_Questions.md`: 12 tasks
- `Solutions.md`: worked solution guidance and code

## Run
From the repository root: `pip install -r requirements.txt`, then launch Jupyter and run all cells. In Colab, upload the relevant CSV files from `data/` and adjust the data path if needed.

All datasets are synthetic and generated for educational use.
